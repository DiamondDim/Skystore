# Skystore

Учебный проект интернет-магазина плагинов и примеров кода, разработанный в рамках курса Python-разработки Skypro.

## 📌 Описание

Проект представляет собой веб-приложение с каталогом товаров и страницей обратной связи. Особое внимание уделено чистоте кода, правильной архитектуре (паттерн MTV), валидации данных, работе с ORM и эстетике пользовательского интерфейса.

## ✨ Реализованный функционал

### Homework-22: Знакомство с Django
- Настройка проекта Django с использованием менеджера зависимостей **Poetry**.
- Создание и регистрация приложения `catalog`.
- Реализация маршрутизации (URLconf) с правильными окончаниями `/`.
- Создание HTML-шаблонов главной страницы и страницы контактов с использованием **Bootstrap 5**.
- Кастомная стилизация в мягких оливковых тонах (шрифт Montserrat, адаптивные карточки, тени).
- Реализация контроллеров (Views) для обработки GET и POST-запросов.
- Интеграция библиотеки `intl-tel-input` для маски и валидации международных номеров телефонов на клиенте + дублирующая валидация через регулярные выражения на сервере.

### Homework-23: Работа с ORM в Django
- Подключение СУБД **PostgreSQL** с выносом чувствительных данных в `.env`.
- Создание моделей `Category` и `Product` с полями, классом `Meta` и методом `__str__`.
- Связь моделей через `ForeignKey`.
- Настройка административной панели: фильтрация, поиск, кастомное отображение.
- Выполнение ORM-запросов через Django Shell (создание, выборка, фильтрация, обновление, удаление).
- Создание фикстур (`fixtures`) для моделей.
- Реализация кастомной команды `load_test_data` для автоматической загрузки тестовых данных с предварительной очисткой БД.
- Настройка работы с медиафайлами (`MEDIA_URL`, `MEDIA_ROOT`, Pillow).

### Homework-24: Шаблонизация в Django
- **Базовый шаблон `base.html`** с блоками `{% block title %}`, `{% block content %}`, `{% block scripts %}`. Все страницы наследуют его через `{% extends %}`.
- **Подшаблон меню `partials/navbar.html`**, подключаемый во все страницы через `{% include %}`.
- **Детальная страница товара** (`/products/<int:pk>/`, нейминг `product_detail`) с отображением изображения, названия, описания, цены, категории и дат.
- **Каталог товаров** (`/catalog/`) с выводом списка через цикл `{% for %}`, обрезкой описания до 100 символов (`truncatechars:100`) и фильтрацией по категориям.
- **Главная страница как лендинг-визитка** с кнопкой перехода в каталог.
- **Форма добавления товара** (`/add/`) с использованием `ModelForm`, валидацией и сохранением в БД.
- **Умная навигация в футере**: категории «Рассылки» и «Полезные утилиты» ведут на карточки конкретных товаров, остальные категории показывают сообщение «Товаров пока нет. Обратитесь к администратору».
- Двусторонние переходы: главная ↔ каталог ↔ товар.

## 🔐 Переменные окружения

Создайте файл `.env` в корне проекта на основе `.env.example` и заполните его своими данными:

```env
DB_NAME=skystore_db
DB_USER=postgres
DB_PASSWORD=ваш_пароль
DB_HOST=localhost
DB_PORT=5432
SECRET_KEY=ваш_секретный_ключ
DEBUG=True
```

#### ⚠️ Важно: файл .env не должен попадать в репозиторий — он добавлен в .gitignore.

## 🚀 Установка и запуск

- 1.Клонируйте репозиторий:
```
   git clone <url-репозитория>
   cd Skystore
```
- 2.Установите зависимости через Poetry:
```
   poetry install
```
- 3.Создайте файл .env по образцу .env.example и заполните его.
- 4.Примените миграции для создания структуры БД:
```
      poetry run python manage.py migrate
```
- 5.Создайте суперпользователя для доступа к админке:
```
      poetry run python manage.py createsuperuser
```
- 6.(Опционально) Загрузите тестовые данные с помощью кастомной команды:
```
      poetry run python manage.py load_test_data
```
- 7.Запустите сервер разработки:
```
      poetry run python manage.py runserver
```
- 8.Откройте браузер и перейдите по адресу: http://127.0.0.1:8000/
- Административная панель: http://127.0.0.1:8000/admin/
- Страница контактов: http://127.0.0.1:8000/contacts/
- Каталог товаров: http://127.0.0.1:8000/catalog/
- Добавить товар: http://127.0.0.1:8000/add/

## 📝 Команды управления
| Команда | Описание |
|---------|----------|
| `poetry run python manage.py migrate` | Применение миграций |
| `poetry run python manage.py makemigrations` | Создание новых миграций |
| `poetry run python manage.py createsuperuser` | Создание суперпользователя |
| `poetry run python manage.py shell` | Запуск Django Shell |
| `poetry run python manage.py load_test_data` | Загрузка тестовых данных |
| `poetry run python manage.py dumpdata` | Экспорт данных в фикстуры |
| `poetry run python manage.py runserver` | Запуск сервера разработки |
