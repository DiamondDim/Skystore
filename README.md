# Skystore

Учебный проект интернет-магазина плагинов и примеров кода, разработанный в рамках курса по Django.

## 📌 Описание
Проект представляет собой базовую структуру веб-приложения с каталогом товаров и страницей обратной связи. Особое внимание уделено чистоте кода, правильной архитектуре (паттерн MTV), валидации данных и эстетике пользовательского интерфейса.

## ✨ Реализованный функционал (Homework-22)
- Настройка проекта Django с использованием менеджера зависимостей Poetry.
- Создание и регистрация приложения `catalog`.
- Реализация маршрутизации (URLconf) с правильными окончаниями `/`.
- Создание HTML-шаблонов главной страницы и страницы контактов с использованием фреймворка Bootstrap 5.
- Кастомная стилизация в мягких оливковых тонах (шрифт Montserrat, адаптивные карточки, тени).
- Реализация контроллеров (Views) для обработки GET и POST-запросов.
- **Дополнительно:** Интеграция библиотеки `intl-tel-input` для маски и валидации международных номеров телефонов на клиенте + дублирующая валидация через регулярные выражения на сервере (Django).

## 🛠 Технологический стек
- Python 3.13+
- Django 6.1.1
- Poetry (управление зависимостями)
- HTML5, CSS3, Bootstrap 5
- JavaScript (intl-tel-input)
- Git / GitHub (GitFlow)

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd Skystore
2. Установите зависимости через Poetry:
   ~~~
   poetry install
   ~~~
3. Примените миграции (для создания базы данных SQLite):
   ~~~
      poetry run python manage.py migrate
   ~~~
4. Запустите сервер
   ~~~
      poetry run python manage.py runserver
   ~~~
5. Откройте браузер и перейдите по адресу: http://127.0.0.1:8000/
